# 工具网站

这里不是“网址大全”，而是一份经过筛选的工具清单。每个条目尽量写清楚：它解决什么问题、什么场景下值得用、有没有需要注意的限制。

左侧目录会自动收录 `docs/tools/` 下的新文件。

## 收录原则

- **真的用过**，或者至少完整了解过它的能力边界
- 能解决一个具体问题，而不是“看起来很厉害”
- 免费、开源或价格透明的优先
- 涉及账号、隐私或付费时，明确写出注意事项

## 示例条目

- [Excalidraw：手绘风格白板](/tools/excalidraw)：适合画架构草图、流程示意和临时讲解图
- 新工具笔记直接放在 `docs/tools/` 下即可，不需要改导航配置
