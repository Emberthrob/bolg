# Excalidraw：手绘风格白板

[Excalidraw](https://excalidraw.com/) 是一个开源的在线白板，画出来的线条带一点手绘感，适合做架构草图、流程示意和会议里的临时讲解图。

## 适合的场景

- 画系统结构、数据流向、部署拓扑
- 给文章配一张“能看懂就行”的示意图
- 开会时快速画流程，边讲边改
- 不想打开重型设计软件的时候

## 喜欢它的原因

1. **打开就能画**：不需要登录，也没有复杂的图层系统。
2. **手绘风格降低压迫感**：草图阶段不需要精修，先把想法画清楚更重要。
3. **导出方便**：可以导出 PNG、SVG，也可以保存为 `.excalidraw` 源文件继续编辑。
4. **支持本地优先**：可以直接在浏览器里用，也可以接入自己的存储。

## 使用时注意

::: warning 先确认存储方式
在线版默认把画布保存在浏览器本地。换设备、清缓存之前，记得导出 `.excalidraw` 文件或 PNG。需要多人协作时再考虑登录和云端同步。
:::

## 在笔记里放图

把导出的图片放进当前笔记所在目录的 `assets/` 文件夹，然后在 Markdown 里用相对路径引用：

```md
![系统结构草图](./assets/system-diagram.png)
```

VitePress 会正确打包和显示。不要把 Obsidian 的 `![[图片.png]]` 语法直接用于博客，VitePress 不认识这种写法。
