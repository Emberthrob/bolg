# 操作教程

这里放可以“直接照着做”的步骤。尽量写清楚每一步在哪里点、填什么、做完之后怎么确认成功，以及最容易踩的坑。

左侧目录会自动读取 `docs/guides/` 下的文件。

## 建议阅读顺序

1. [新增一篇笔记](/guides/new-note)：搞清目录约定、frontmatter 和图片引用方式
2. [部署到 Cloudflare Pages](/guides/cloudflare-pages)：从连接 GitHub 到绑定 `blog.bfreegpt.com`
3. [Obsidian 多端同步](/guides/obsidian-sync)：电脑和手机共用一个仓库，自动同步

::: tip 先看结论
日常写作只需要记住三件事：**在四个栏目目录里新建 `.md`**、**用标准 Markdown 链接和图片**、**同步到 GitHub 的 `main` 分支**。剩下的导航和部署都是自动的。
:::
