# 游戏攻略

这里记录玩过的游戏和真正有用的攻略：不是把百科抄一遍，而是写“我在这个阶段应该做什么”“这个机制为什么重要”“哪里容易卡住”。

左侧目录会自动读取 `docs/games/` 下的内容，新增攻略不需要改导航。

## 写法约定

- 开头写清楚**适用版本**和**适用阶段**，避免过期攻略误导人
- 关键数值、路线和材料单独列出来，方便直接照着做
- 剧透内容放在折叠块或单独章节，并提前标注
- 标明是原创、实测，还是整理自社区资料
