# 示例攻略：先把资源循环跑通

> 这是一篇**结构示例**，不是某一款具体游戏的完整攻略。写新攻略时可以照着这个骨架替换内容。

## 适用版本与阶段

- 游戏版本：`x.y.z`
- 适用阶段：第一次开荒 / 中期扩产 / 回归玩家
- 最后更新：2026-10-23
- 是否含剧透：否

## 核心思路

开荒期最容易犯的错误，是看到什么资源就采什么，结果仓库里堆了一堆暂时用不上的材料，真正卡进度的资源却一直缺。

更稳的做法是先跑通一个最小循环：

```text
获取基础资源 → 解锁关键设施 → 提升采集效率 → 再回头补缺口
```

## 前 30 分钟做什么

1. **只拿当前任务需要的资源**，不要顺手清空地图。
2. 优先解锁能持续产出资源的设施，而不是一次性奖励。
3. 把背包和仓库容量升到“不会频繁中断采集”的程度。
4. 记下第一个卡点需要的材料，再决定下一步去哪。

::: tip 一个简单的判断标准
如果某个操作不能让你下一次采集更快、或不能减少往返次数，那它在开荒前期大概率不是优先项。
:::

## 常见卡点

| 卡点 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 资源够了但解锁不了 | 前置任务没做 | 回任务列表确认前置条件 |
| 采集效率低 | 工具等级不够 | 先升级工具，再扩大采集范围 |
| 背包总是满 | 带了太多暂时没用的材料 | 只带当前目标需要的数量 |
| 来回跑图太频繁 | 没有就近存放点 | 在资源区附近设置临时仓库 |

## 中后期怎么扩展

- 把单次采集的收益和往返时间一起算，不要只看单次数量。
- 先补瓶颈环节，再整体扩产；否则只是把堵点往后推。
- 每次版本更新后，重新确认关键数值有没有变化。

## 复盘

打完一个阶段后，记下三件事：

1. 哪个决策最省时间？
2. 哪个资源最后剩得最多？
3. 下一次开荒会改变哪一步？

这三条比“抄一份完美路线”更有用。
