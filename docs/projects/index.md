# 项目说明

这里是 Emberthrob 的个人知识库中「项目」栏目的入口。它放“我做过什么”以及“为什么这样做”。不是作品集式的展示页，而是能回头查的实现笔记：目标、技术选型、关键步骤、踩坑记录和后续想法。

左侧目录会自动读取本文件夹里的 Markdown 文件。新增项目笔记时，不需要改任何配置。

## 适合放什么

- 一个网站、脚本或小工具从 0 到 1 的过程
- 技术选型与替代方案对比
- 部署、域名、自动化流程的记录
- 做完之后的复盘：哪里可以更好

## 从这里开始

- [本站是怎么搭起来的](/projects/how-this-site-works)：VitePress + 自动导航 + Cloudflare Pages 的完整结构
- 新建项目笔记：在 `docs/projects/` 下创建 `.md` 文件即可，文件名建议用英文短横线，标题写在 frontmatter 的 `title` 里
